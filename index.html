Settings

With a free YouTube key the site fetches the trending videos by itself every day, including all channel info. The key stays in this browser only.

How do I get a key?
  1. Go to console.cloud.google.com and create a project.
  2. Under "APIs & Services", search for YouTube Data API v3 and enable it.
  3. Choose "Credentials" → "Create credentials" → "API key".
  4. Paste the key above. Free up to 10,000 units a day; this site uses about 2 per day.
